Known limitation — disclosed on purpose

International / cross-border payments settled in INR after FX conversion are not modeled. TieOut has no currency-conversion logic, so it correctly refuses to auto-close these (it never mis-closes a case it doesn't understand) — but it can only label the discrepancy a generic amount_mismatch, not identify the true FX cause. This is a safe-failure gap: it over-flags rather than guessing, and we're stating it here rather than hiding it.
